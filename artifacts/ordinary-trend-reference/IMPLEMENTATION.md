# 唯一普通趋势参照的实施边界

基线固定 main 58d4b9cf7c91b04bf98e970a2ce546f66ee5112d。仓库现有 competitor 是其他项目的冻结结果校验，不是相同账户、角色与风控下的3/6/20参照；检索未找到可直接复用的同定义实现，因此实现附件固定R。

实际调用链仍为 ProductionEngine.decide → 日频独立风险评估 → PortfolioAllocator.allocate → 共同 AllocationBook → plan_orders → 真实 next-open ExecutionPlanner。没有第二资金账本、回灌基线状态或模拟已成交目标。

- 替换普通 `_core_candidates` 筛选、普通持仓结构/换仓判断及 `add_mature_leaders` ADD目标。R的新目标和R待成交延续不再调用原普通资格、评分或ADD判断。
- 战略grant/epoch、确认恢复cohort、战术恢复、已授权账户修复、冲击后实仓恢复仍由原实现管理。原普通市场观察中被这些恢复权限使用的部分保留。R不能借用它们的授权；已有恢复或战略所有者由原退出路径管理。
- 普通入选依据是121个有效收盘形成的120日收益、最后120日均线。仅保留既有数据完整性置信度、有效行业、当日有效OHLC/成交量/金额及既有金额流动性检查；没有旧结构、成熟评分或入场确认的叠加。
- 排名在当前可由普通职责管理的候选中进行；保留前6名内实际持仓，最多3只。未成交退出仍占现金与席位，故轮动可以等待到下一次20日评估；不虚构换仓当日已经卖出。
- 等权目标以风险总仓上限扣除其他真实承诺后的普通预算计算，逐请求再用原单名/行业/相关性/持仓数约束分配，缺额留现金。已有损伤修复资本责任仍受原入门预算约束。
- 共同宽基/科技指数的完整已知交易日历提供零起点ordinal，ordinal % 20 == 0评估，账户起点与删除证券不改变时钟。每天照常计算风险与强制保护；非调仓日持有实际价格漂移，已发订单按当前资金和基础数据保障延续。
- 新增的是当次决策诊断中的时钟、排名与普通请求记录，不新增持久账户状态或公开参数。3/6/20/120是真实规则常数，不以隐藏常量宣称无复杂度。

研究实现保留未调用的旧普通辅助函数以便审查差异，并不宣称已完成删除或生产简化。只有R晋级才退役这些被替换职责、清理无用辅助函数和相应旧测试。若经济失败，候选不合并，main继续是唯一生产版本。

基线原件不改生产者身份。新旧任务合同哈希不同属有意变更，比较不伪造为同一合同；账户配置、冻结行情、证券、日期、成本、原生回放器与运行时必须完全一致。四组B原件对应的经济源码与当前main逐文件指纹一致。

原生B保存的是实际日目标、风险、仓位、现金及成交，不包含每条被拒资格的完整反事实状态。配对归因可以证明真实路径收益差，不能单凭R选中而B未买就证明B某个门槛有错；报告明确保留这一归因边界。
