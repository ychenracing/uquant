# 2026-09-25 改造诊断证据

> **权威级别：历史证据**

本目录记录 2026-09-25 改造分支上生成的一次性诊断结果，不是当前生产合同，也不替代
[性能与证据](../../docs/PERFORMANCE.md)中的正式验收。15× 与 23.284× 等现行门槛不因这里的
相对结果改变；固定的 34 只股票池是事后选定的研究输入，所有回放都是以此为条件的历史回放
（`universe_selection_status=retrospective_fixed`、`evidence_scope=conditional_historical_replay`、
`historical_membership_evidence=unresolved`）。

## 来源与运行环境

- 生产源码：`2626035`。其后的提交只做行为等价重构、测试与治理登记，经相同测试集核对订单、
  成交和数量一致，未重新运行这些诊断。
- 数据：`data/frozen`（前复权股票行情，没有公司行动事件；指数为原始点位）。
- 运行时：Python 3.12.3、NumPy 2.5.1、pandas 3.0.5，`uv.lock` 未改动（验收合同要求的 3.12.13 只用于测试）。

## 主要观察

- 版本链：B0 21.87× → E1 21.92×（首次分歧 2023-01-09 sz300308 买入数量 33,300→30,500，
  竞价按前收盘定量）→ D1 与 E1 相同（冻结数据没有公司行动，容量修复未触发）→ S1(v1) 22.31×
  → T1 26.76×（v2 行业修订使 2024-07-26 起的卖出路径改变）。最大回撤均约 26.7%。
  各阶段差额受路径依赖影响，不能相加。
- 相对参照（三只核心股票）：REF0a 62.1×/回撤 56%，REF0b 63.1×/55%，REF3 与 REF0b 相同
  （k=3 等于全部持有），REF1 沪深300 1.28×/25%；策略 26.8×/26.7%。在事后选定的赢家池内，
  简单持有的财富更高但回撤约为两倍。
- 34 只全集参照：REF3 31.2×/52%，REF0a 14.4×/42%，REF0b 11.2×/43%。
- 执行压力：基准 26.76×、回撤 26.7%、未成交提交 3.4%；成本压力（滑点 0.4%）26.4×、回撤 26.9%、
  未成交 12.5%；成交压力（参与率 0.125%）25.2×、回撤 34.1%、未成交 13.6%。
- 起点窗口（重叠，不是独立样本）：12 个月财富 1.09×—5.40×。
- 消融：三项机制在两个案例中都没有改变任何成交；这说明它们在当前路径上处于休眠状态，
  但两段历史不足以单独证明可以删除。
- 数据检查：捕获 sz000636 的 647 个无停牌解释缺口，以及 sz000636/sh688347 共 1,232 行
  “有成交量、零成交额”记录。
