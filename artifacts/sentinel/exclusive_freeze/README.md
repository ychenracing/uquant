# Sentinel Exclusive Freeze Evidence

This directory contains the compact, auditable evidence for the locked Stage 7
candidate. The candidate may only enable Phase 6 causal confirmation as an
additional owner of the existing `freeze_new_risk` flag.

`phase6_baseline.json` binds the exact starting main tree and AccountState schema.
`candidate_lock.json` fixes every reviewed parameter before any official economic
matrix. Later artifacts retain the first behavior divergence, all exclusive-freeze
events, opportunity-cost diagnostics, economic summaries, migration proof, and the
terminal PROMOTE or REJECT decision.

The directory does not contain large equity curves. Counterfactual 5/10/20-session
returns are diagnostics and are never represented as accounting PnL.
