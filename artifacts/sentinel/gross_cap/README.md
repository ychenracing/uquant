# Sentinel limited gross-cap evidence

`candidate_lock.json` is the pre-registered Phase 5 candidate. Its 70%/50% caps,
two-session confirmation and three-session repair rules are immutable for the
official paired evidence. Research-only alternatives are explicitly excluded.

`a_h1_2024_paired.json` is generated by `research/sentinel_cap_ablation.py` from
an exact Freeze-only counterfactual and the locked candidate using identical code,
data, symbols and dates. Cash drag is a non-accounting diagnostic. Avoided
drawdown, post-release recovery cost, order attribution and turnover attribution
are computed both for the full window and for each binding-cap segment.

The candidate is not an activated Holdout Lane. If a mandatory gate fails, Phase
5 stops, production remains Freeze-only, and no activation session is assigned.
