# 目标调整建议（提案，尚未生效）

## 判断

目标的经济意图合理：在可承担风险与操作成本内，建立可重复执行、成本后有优势的AI趋势策略。反复失败没有证明这个目标不可能；也没有证明仅靠现有量价信息和历史样本必然可以实现。执行方法的问题也不能全部归咎于用户目标：应更早区分数据修复、机制失败、组合代价和独立证据不足，及时结束缺少新信息的改造。

当前目标把集中行情的收益保护、跨主线参与、恢复速度、低订单数量、简化及独立泛化一起作为终点，缺少冲突时的明确优先级。最优方向只能是当前证据下的选择，不能承诺有限次改造找到全局最优。

## 推荐的新目标结构

建议先调整优先级与交付阶段，不急于再降低数值门槛。当前已有32单等有效授权，必须正确应用。新的风险或操作预算变更只在实际偏好发生变化时提出，不以某个候选刚好通过为依据。

| 层次 | 建议定义 | 需要保留的证据 |
|---|---|---|
| 使用场景 | 明确历史可见的AI相关候选范围；有趋势且风险允许时参与，缺少合格机会时允许现金 | 当时可得成员与信息、实际入场及未入场理由，限定可声称的适用范围 |
| 首要经济目标 | 在预先确定的风险与人工操作预算内，提高相对固定可执行基准的成本后收益 | 同输入原生账户、费用与滑点、全组合路径，不以单笔赢家或峰值财富替代 |
| 风险与正确性 | 保留现有回撤和风险权限；无未来信息、真实次日成交、完整对账、不可篡改证据 | 不能以更好收益抵消账本错误或违规风险 |
| 龙头与轮动 | 捕获一部分可持续趋势，证明能够在合格且获授权时转入其他机会 | 不要求命中全部事后龙头；利润集中披露且做实际删除压力测试，不强制每行业平均盈利 |
| 交易与简化 | 以用户实际每周/月可承受的执行次数、成本、规则数量定义负担；效果接近时优先简单方案 | 不按当前32单成绩倒推新上限；先定操作预算，再冻结未来评价口径 |
| 泛化 | 明确区分历史研究支持、其他预先固定公司上的迁移、冻结后的独立观察 | 研究过的样本不重新命名为样本外；记录所有选择历史，不能随试验次数增加而增加置信度 |

建议目标表述：在明确、具有时点依据的AI股票研究范围内，交付一套日频信号、次日手动执行的现金多头趋势系统；以预先确定的风险和操作预算为硬边界，优先提高相对固定可执行基准的成本后收益。接受空仓、部分假突破和收益集中，要求完整披露并验证相应代价。历史研究版本与独立验证合格版本分别交付；独立优势尚未建立时，不宣称可投入资金或未来盈利已获证明。

交易负担的具体例子：23家公司队列里，主策略22单分布在19个订单信号日，候选32单分布在25日；单月最多均为5单，单日最多分别3单和4单。多10笔订单增加了6个信号日。这不是放宽既有上限的授权，但说明总单数与人工负担并不等价，应按实际操作需求预先定预算。这里统计的是订单信号日，不冒充人工实际完成记录。

## 完成与退出条件

第一层交付是工程可用、行为清楚、全部证据可复查且历史筛选有根据的候选。它仍可能不具备投入资金条件。第二层是候选冻结后，在未用于规则选择的数据上、按预先登记的评价方式验证经济优势；需要适当的样本长度与有效机会数量，不能仅以几周无亏损宣布通过。

若合理路线被现有证据否定，且不存在新的可检验信息、机制或已确认错误，建议允许交付“当前约束下未建立有效策略”的研究结论与保留基线，等待改变前提的新信息。单次候选失败不自动触发这一结束条件；同样，也不为了保持工作状态而继续换指标。具体采用这个结束条件会改变原来持续直到成功的任务定义，需要用户明确认可。

新目标若获认可，应建立独立版本：保留旧合同及原FAIL，披露调整发生在观察哪些候选之后，不将新门槛回填成旧研究通过。已经看过的历史可用于诊断，不能用于独立证明新目标被满足。新收益百分比与交易次数应从资本风险/操作预算和策略职责决定，本提案不凭当前成绩给出一个更容易通过的数字。
