no main merge, no production-pool expansion, no data after 2026-08-05.

Implement an explicit context for a hash-pinned taxonomy on the existing
AIUniverse contract. The normal loader and frozen manifests stay unchanged.
Membership intervals are identical. Revisions apply only after known-by and
membership activation; earlier dates retain the old label. Decision scoring,
reference breadth, risk, qualification and account attribution share this
input. Cache identity includes it; account validation requires the same input
and rejects research accounts in normal production. No monkeypatch.

the main-control source/tree before running economic comparisons. Both input
arms run the same patched source, default config, 2m initial cash, frozen data,
next-open real execution, costs, risk and attribution checks.

First: 2023-01-03..2023-01-10 native identity sentinel, old and revised full
pool. An engineering failure is repaired and only the affected sentinel is
repeated, with failed output kept. Prove normal-default neutrality against the
unmodified main six-session sentinel before larger runs.

Then exactly three paired scenarios, 2023-01-03..2026-08-05:
1. full, no exclusions;
2. remove_all_three;
3. remove_all_three plus sz300666 (strict).
Membership and role sets must be equal between arms on every date. This is
not no_optical: changing classification must not change scenario membership.
At most three independent worker processes, one writer per result directory.
Read back every complete account with the native reader. No parameter search,
additional economic candidates, frozen gate replacement or full L4 matrix.

Report wealth/DD/orders/costs, symbol and revised-industry contributions,
first score/reference/qualification/risk/target/fill divergence. Account
identity/event-ID differences alone are not economic divergence. A profitable
change concentrated in an existing winner does not establish generalization.

Reuse the full run's native observations for same-date all/mature non-optical
ranking diagnostics: every 60 sessions, horizons20/60, next-open endpoints
bounded by2026-08-05; score/momentum/industry-first against cohort equal weight.
Use common valid cohorts/anchors between arms; disclose missing endpoints and
the cohort's dependence on old-pool selection. No new score fitting or new
revenue filter without sufficient dated original data.

Follow-up: diagnose the first causal branch, including original H1 all-role
removal, using saved observations. Only if a specific reference-role defect
is evidenced, register one isolated role comparison (two arms, one variable)
before running it. Preserve all-role exclusion contract. Otherwise close
that hypothesis and deliver a dated opportunity-coverage gap ledger and a
minimal next-data specification, without pretending to establish historical
membership or expanding production. Holding/reentry changes require repeated
identified missed-opportunity evidence and a false-positive check.

This bounded project ends with verified integration, paired evidence,
diagnosis and a conditional decision on each proposed direction, saved and
pushed to PR56. Overall profitability/generalization remains unproven unless
the separate frozen acceptance and independent validation actually pass.
