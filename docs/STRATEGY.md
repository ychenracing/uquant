# uquant 策略与风控

## 策略定位

uquant 是科技产业链的日频趋势与领涨组合策略。它不预测分钟级价格，也不进行日内套利。系统通过领涨确认参与强趋势，通过迟滞与低换手规则延长有效持有，在市场结构破坏时由独立风险状态机降低总仓位，并在修复阶段分层恢复。

## 机会状态

| 状态 | 含义 | 组合倾向 |
|---|---|---|
| `STRONG_TREND` | 指数、广度和成熟领涨共同确认 | 允许接近满仓，优先集中成熟领涨 |
| `TREND` | 趋势成立但强度或集中度较低 | 逐步提高仓位，保留分散与迟滞 |
| `RECOVERY` | 冲击后市场与持仓开始修复 | 先探针、后确认，保护恢复锚点 |
| `CHOPPY` | 证据混合、趋势持续性不足 | 降低目标仓位，减少轮动和追涨 |
| `WEAK` | 指数和广度持续偏弱 | 只保留受风控允许的低仓位 |

状态切换不是单日阈值判断。广度、指数趋势和快速修复证据必须连续出现；证据消失后也要经过确认才退出，降低来回切换。

## 领涨评分

每只可见证券的评分由以下信息共同组成：

- 20、60、120 日收益与相对指数强度；
- 收盘价相对 20、60、120 日均线的位置；
- 突破前高的程度；
- 120 日回撤韧性；
- 成交量扩张；
- 短中期动量加速度；
- 可用历史长度和行业归属。

截面位置以固定参考篮子计算，避免用户临时增删候选股时重新定义全部排名。`mature` 与 `emerging` 需要分数、置信度、历史长度和连续天数共同满足。候选股进入组合还要通过流动性、行业集中、相关性和替换优势检查。

## 持仓生命周期

| 生命周期 | 用途 |
|---|---|
| `CORE` | 已确认的核心趋势仓位 |
| `ADD1` | 首次盈利确认后的加仓 |
| `ADD2` | 更高浮盈与趋势延续后的第二次加仓 |
| `SATELLITE` | 小权重的新兴机会或分散仓位 |
| `RECOVERY` | 冲击修复阶段的锚点或探针 |

加仓必须满足最小有利波动和组合级冷却期，并检查指数短期涨幅，避免连续追高。替换需要持续优势、最短持有期和轮动频率预算；目标差异不足时保持不动。

## 战略组合与动态持仓数

默认配置包含一个三证券战略先验 `sz300308`、`sz300394`、`sz300502`。它只有在长期收益和连续确认达到要求时才激活，不会因为回放起点较早而永久冻结，也不会对不在用户候选池中的证券强制建仓。

除明确先验外，系统可以从用户候选池中按证据发现成熟组合。目标持仓数根据可用领涨、市场状态、行业分散和相关性动态变化，但始终不超过 6。

## 风险雷达

风险状态使用以下相互独立的证据：

- 参考篮子短期平均收益与下跌广度；
- 跌破 MA20 的比例；
- 多行业同步走弱；
- 横截面相关性抬升；
- 短期波动相对常态放大；
- 成熟领涨失效；
- 宽基和科技指数下跌速度；
- 当前持仓的集中破坏；
- 组合运行回撤和资本回撤。

| 风险状态 | 作用 |
|---|---|
| `NORMAL` | 不额外压低机会轴给出的仓位 |
| `CAUTION` | 多项早期风险同时出现时降低仓位 |
| `RISK_OFF` | 结构破坏或资本回撤扩大时继续收缩 |
| `CRISIS` | 严重冲击时进入最低风险预算或清仓路径 |

运行回撤用于当前部署周期，空仓后重置；资本回撤从账户历史高点计算，不因空仓重置。资本保护复发后会进入冷却期，防止一次短暂反弹立即恢复高风险。

## 冲击与恢复

冲击严重度区分普通、集中破坏、参考篮子不完整、极端下跌和锚点破坏。恢复并非风险状态的简单反向阈值，而是要求：

- 指数重新出现正向冲量；
- 市场广度修复；
- 持仓或候选股重回关键均线；
- 严重冲击已经过最短等待期；
- 普通快速修复与长期单仓修复不相互抢跑；
- 恢复失败后重新触发资本保护与冷却。

恢复锚点只在仍持仓、仍有相关挂单或仍处于冲击修复阶段时保留。完整退出后旧锚点会退役，不能在后续周期重新夺取组合控制权。

## 交易次数控制

系统通过以下机制降低换手：

- 目标权重迟滞和最小交易金额；
- 核心趋势仓位不因每日价格漂移机械再平衡；
- 成熟领涨的连续确认和最短持有期；
- 替换优势与连续天数要求；
- 20 日轮动次数预算；
- 加仓冷却；
- 不变的挂单复用同一订单；
- 被涨跌停、停牌或容量阻塞时保留原意图。

## 已知边界

- 日频模型无法处理盘中突发事件和盘口冲击；
- 行业映射为静态配置，需要在证券业务发生实质变化时维护；
- 参考篮子不足会拒绝运行，不会用少量证券近似市场广度；
- AkShare 刷新只覆盖股票前复权行情，指数仍需原始指数数据源；
- 历史回放使用开盘成交模型，真实成交可能因排队、流动性和人工操作而不同；
- 固定参数不保证适应未来全部市场结构。
