# 本轮诊断：启动、锚点与股票池

基线为 main `7e2b0fd09305dcb55d51f1606f24ba99a8bb1721`，Z 生产指纹
`18912bdf6b98826b86fc49c4ad4ff5c7cc29382fa11b71b0fbb7cbb2d589fd3f`。
只使用截至 2026-08-05 的既有历史回放。以下事实来自原始账户、逐日观察和

## 启动差异

去三巨头 offset20 的真实起点为 2023-02-07。正常起点在 2023-03-06 给
sh688256 生成普通买单（目标 50%）；offset20 同日没有买单。两者当日市场、
候选与结构检查相同，但正常账户有三组风险锚点，offset20 尚无风险锚点。
正常账户取得 FULL_COHORT established 证书，offset20 的独立资格未通过。
两者已有 established 观察分别为 23 与 20 日，均超过所需确认；因此不能把
差异简单归因于候选尚未观察足够天数。

offset20 直到 2023-04-04 才同时买入 sh688012、sh688041、sh688256，
目标各 26.67%，之后经历实际风险减仓和结构退出。2023-06-29 全部现金，
资金损伤级别 3；直到 2024-12-23 账户资金修复 READY，12-26 才再次买入。
健康计数期间还受风险票、市场损伤、参考覆盖等真实限制。不能据此放松这些守卫，
也不能用战略 epoch 结算修复解释这个没有战略 epoch 的账户。

## 第一机制：锚点篮子身份

调用链：风险评估 → `risk/anchors.py` 的候选选择与确认 → risk evidence →
战略 quorum/普通资格 → 共享资金账本 → Target/Order/Fill。

`_dynamic_anchor_candidate` 用评分排序，但 `_update_dynamic_anchors` 将有序
逗号字符串当作篮子身份。同一组成员仅排名改变会清零候选确认；已生效篮子在
相同成员的新排序连续出现后还会被当作重新锚定，清空 armed/break 状态。
offset20 原观察中找到 155 次相邻日成员相同、顺序不同的候选变化；其中部分
日期本来处于风险关闭阶段，不能把 155 次都算作可交易机会损失。

三个定向测试证明：原实现无法在交替排序的同一篮子上完成五次确认，且会重设
相同篮子的风险记忆；真正更换成员仍须重新确认。候选只把身份比较改为成员集合，
保留实际保存的顺序、篮子成员选择、行业覆盖、五日确认和健康阶段要求。
风险状态影响全局，因此小筛选成功后仍需覆盖完整本轮必要人群。

这证明状态缺陷及修复行为，不预先证明经济改善。原生短 sentinel 完成 24 日、
财富 1 倍、账目与身份读回通过；完整经济筛选结果另行封存。

## a/b 对照与替代方向

a/h1_2024 与 b/h1_2024 的六笔订单相同：01-03 三只光通信各三分之一入场，
01-17 退出两只，01-31 退出最后一只，财富均约 0.915362。新增两只股票没有
改变这组订单，不能把该窗口亏损归因于新增股票挤占预算。

a/bull_crash_2025_2026 从 04-03 的战术反弹买入参与光通信，随后形成恢复组合；
b 同窗口先在 02-07 买入 sh603986，03-25 结构退出，之后才于 07-15、07-29
参与光通信。sh603986 的净归因约 -140,912.28 元。这说明先前持仓路径影响
后续恢复，但单笔事后亏损不足以否定当时资格或调整排序。

若第一机制未达到交付条件，再检查该新增候选在当日是否存在资格比较、无效占用
或排序缺陷；无机制证据不写日期、股票或亏损案例专用规则，也不重做 AA/AB。


## 本轮有限探索结论

第一候选的五个完整筛选账户与 Z 的财富、回撤及订单数相同。四个冻结目标中
已完成的三个均无改善，即使剩下一个改善，也达不到至少两个条件改善的要求。
因此拒绝第一候选，不以状态正确性修复冒充经济泛化增强。

第二候选预注册后才实施：仅在尚未建立生效锚点时，保留仍满足当前评分、置信度、
成员数和行业覆盖条件的原提名，避免更强的新候选反复打断确认；失去资格立即
重新选择，风险不健康仍清空确认。参数、预算与确认天数均不变。
2023-02-07 的原三组提名到 02-13 持续合格，原机制却因新增候选更替而重启确认。
修改后的真实买单于 02-13 出现，说明改变确实进入订单路径。

第二候选改善去三巨头 offset20，但无光通信 offset20 的财富由 2.116899619
降至 1.924813996，回撤由 21.919000% 升至 24.409701%。增加 2.490701 个
百分点，超过事前冻结并含 10% 浮动的 2.2 个百分点上限。更早买入改变后续
资本和持仓路径；这是真实机制代价，未发现足以解释为实现错误的证据。

两条机制均不具备交付资格。保留 main 上 Z，不运行最终大矩阵，不追加第三条
路线，不合并本 PR 的候选策略。冻结计划与历史合同保持原样；模拟操作卡作为
准备资料保留在本分支，未启动自动任务或实盘。详细数值见两个独立筛选结果文件。
这些结果均为反复研究过的历史区间比较，不是独立样本外检验。
