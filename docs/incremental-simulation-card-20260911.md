# 固定版本后的模拟记录操作卡

本轮只准备记录方式，不启动任务、不下单、不读取 2026-08-05 之后的数据。
实际启用时固定已选版本、完整股票池、配置和初始模拟账户，从启用之后的新交易日
逐日记录；版本变化另起一段，不回填既有日期，也不覆盖原有 Future Holdout。

## 每日最小闭环

1. 保存运行前账户与当日数据快照，核验上一日模拟持仓、现金、未成交委托和成交。
2. 盘后执行已有 `uquant daily`，明确指定当日日期、完整股票池、隔离的行情目录、
   模拟账户及模拟快照。该命令保存账户并生成下一交易日意图。
3. 下一交易日人工记录模拟成交或未成交原因及费用，再用于下一次快照核对。
   不把模拟成交写入真实账户，不把模拟价格称为券商成交。
4. 每日按日期保存运行前后账户、输入快照和日报。无订单同样保留。

命令参数与快照 schema 直接复用 [运行手册](OPERATIONS.md) 的 `daily` 示例。
升级已有账户时先在副本上执行 `account-code-migrate` 并核对经济状态摘要；
不要直接改 `code_hash`、重置权益峰值或补造修复来源。

| 必需记录 | 现有来源 |
|---|---|
| 日期、版本、配置、数据身份 | Git 提交、锁文件、日报配置摘要及账户代码/数据摘要 |
| 候选及阻断原因 | 日报 Candidate explanation 与逐票约束表 |
| 目标、委托及关联身份 | 日报目标表、账户 pending_orders / order_ledger |
| 模拟成交、费用、持仓、现金 | 模拟快照及账户 fills / positions / cash |
| 权益与风险状态 | 日报及当日账户快照；权益按同日持仓收盘价与现金复算 |

无需增加服务、配置开关或新记录平台。这里的日常模拟不是历史收益验收，也不自动
取得旧 Holdout lane 的正式评分资格；若另行启用正式 lane，须按
[Holdout 文档](HOLDOUT.md) 的身份和不可变追加要求单独准备。

4–8 周可做首次人工复盘，检查漏单、滑点、风险阻断和持有体验。成交太少时继续
观察，不据此声称统计稳健或未来盈利已得到证明。
